# Issue tracker

This repository tracks work in GitHub Issues for `kyo6/vue3-blog`.

- Use `gh issue list`, `gh issue view`, and `gh issue create` when the user requests issue operations.
- Confirm authentication with `gh auth status` if an operation fails.
- Keep issue descriptions actionable and include the affected route, component, or content path when known.
- Do not create or modify GitHub issues unless the user explicitly asks for that external action.
