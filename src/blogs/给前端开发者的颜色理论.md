前端每天都在和颜色打交道：选色靠感觉，调色靠试错，一换主题就崩。其实颜色背后是一套**可以用数字描述的完整理论**——从色相、饱和度、明度三个维度出发，借助色相环，就能把"这个配色好不好看"变成一道几何题：两个颜色在环上相距多少度。

本文把颜色理论压缩成 4 部分，文字尽量精简，示例全部可运行：SVG 色环、可拖动的 HSL 调色器、六种色调关系的完整对照。

## 1. 色彩三要素：把颜色变成三个数字

参考原图中的概念版：**色相 / 纯度 / 明度**是描述任何一个颜色的三个独立维度。把这三个维度按不同方式组合，就能产出无穷多种颜色——下图中红色系那一排 7 个圆就是同一个色相通过调整纯度和明度演化出来的。

![色彩三要素示意图：色相/纯度/明度三个维度，以及红色系在饱和度与明度上的多种变化](/blog/color-theory/01-three-elements.png)

任何颜色都能拆成三个正交的维度（拾色器里常写作 **H / S / B**，CSS 写作 **HSL**）：

- **H · Hue 色相**：`0–360°`，决定"是什么颜色"，红橙黄绿青蓝紫绕成一圈；
- **S · Saturation 饱和度**：`0–100%`，决定"有多鲜艳"，0% 是灰色；
- **L · Lightness 明度**：`0–100%`，决定"有多亮"，0% 是黑、100% 是白。

三条渐变条直观展示三个维度的变化规律——色相绕一整圈、饱和度从灰到艳、明度从黑到白：

对照 Photoshop 等专业拾色器就能看到三要素的真实映射关系：左边的大色域负责 **S（饱和度）** 和 **B（明度）**（在 H 固定时选颜色），中间竖条选 **H（色相）**，右侧 H/S/B、R/G/B、HEX、C/M/Y/K 多套数值实时同步。这套 UI 是图形软件沿用几十年的"最权威色相环实例"——H/S/B 三个滑杆之所以先于 hex 普及，是因为它们更贴合人眼识别颜色的方式。

![Photoshop 拾色器：左侧大色域选 S/B、中间彩虹条选 H、右侧 H/S/B 和 R/G/B 数值同步显示](/blog/color-theory/02-color-picker.jpg)

> 关键认知：**色相是角度、饱和度是浓度、明度是亮度**，三者互不干扰、各改各的。这正是 `hsl()` 比 hex 直观的原因——调整一个维度，另外两个维度原样保留。

## 2. 色相环的基本形态：原色、间色、复色与冷暖

把 0–360° 的色相绕成一圈，就得到**色相环**（也叫色轮）。每 30° 一个标准色，共 12 个；其中 7 个构成**7 大色相**：红、橙、黄、绿、青、蓝、紫——这是设计行业的最经典分类。配色的所有规则，都是在这个环上"量角度"：

### 2.1 原色 · 间色 · 复色：色相环是怎么长出来的

色相环上的 12 个颜色不是凭空来的，而是由**三原色**逐级混合出来的：

- **原色（Primary）**：红 `0°`、绿 `120°`、蓝 `240°`——不能由其他颜色混出来，是加色法的"原料"，对应屏幕的 **RGB 三通道**；
- **间色（Secondary）**：两原色相加——红+绿=黄 `60°`、绿+蓝=青 `180°`、红+蓝=品红 `300°`，正好落在两原色的正中间；
- **复色（Tertiary）**：原色 + 间色——橙、黄绿、青绿、蓝青、蓝紫、红紫共 6 个，填满 12 段色环。

### 2.3 冷暖色：色相环的"温度"划分

色相环除了按"出身"（原/间/复）和按"锚点"（7 大色相）划分，还能按**温度**划分——这是配色的另一条实用轴线：

- **暖色**：红、橙、黄（偏黄的绿也算暖）——有**前进、膨胀、热烈**的感觉，是"向你靠近"的颜色；

- **中性色**：绿、紫居中，往哪边偏就归哪边。

## 3. 六种色调关系：配色方案的几何学

配色方案的本质就一句话：**选一个主色，再在色环上按固定角度挑搭配色**。夹角越小越柔和，越大越刺激。经典划分是六种关系——同类、类似、邻近、中度、对比、互补。

按对比强度把它们再分三档，看起来更直观：**柔和档**（同类 0° + 类似 30°）适合大面积统一；**中性档**（邻近 60° + 中度 90°）明快又有层次；**强烈档**（对比 120° + 互补 180°）冲击力强但需要谨慎使用：

### 六种关系速查表

| 关系 | 夹角 | 对比强度 | 优点 | 缺点 / 风险 | 救场手段 |
|------|:---:|:---:|------|------|------|
| 同类色 | 0° | 柔和 | 统一、含蓄、专业 | 单调呆板 | 拉大明度差 |
| 类似色 | 30° | 柔和 | 和谐、舒适 | 偏弱、无力 | 提升饱和度差 |
| 邻近色 | 60° | 中性 | 明快、安全 | 偏中性 | 加一个点缀色 |
| 中度色 | 90° | 中性 | 活泼、有层次 | 中性 | 控制面积比例 |
| 对比色 | 120° | 强烈 | 冲击力强 | 廉价、视觉疲劳 | 降饱和 / 减面积 |
| 互补色 | 180° | 最强 | 潮流、兴奋 | 刺眼、疲劳 | 降饱和 / 加黑白灰 |

> **通用救场三招**（对比色、互补色翻车时）：① 降低其中一方的饱和度或明度；② 缩小辅助色面积，主体保持"60% 主色 / 30% 辅色 / 10% 点缀"；③ 用黑白灰或中性背景做缓冲。

## 4. 前端实践：从理论到代码

### 4.1 CSS 里的颜色表示法

同样的颜色，五种写法。hex 是给机器看的，hsl 是给人调的：

```css
:root {
  --brand-hex: #4f46e5;                      /* hex：紧凑，但语义不明 */
  --brand-rgb: rgb(79, 70, 229);             /* rgb：老式调色 */
  --brand-hsl: hsl(245, 76%, 59%);           /* hsl：色相可计算，推荐 */
  --brand-oklch: oklch(0.52 0.21 277);       /* oklch：感知均匀，未来主流 */
  --brand-mix: color-mix(in oklch, var(--brand-hsl) 60%, white); /* 调淡 */
  --brand-light: hsl(from var(--brand-hsl) h s calc(l + 15%));   /* 相对颜色 */
}
```

三者的核心差别一句话：**hex 是 16 进制 RGB 的压缩，hsl 把"色相/浓度/亮度"分开，oklch 让"看起来接近的数值也接近"**。当你想"把主色调亮 15%"时，hsl 和 oklch 一行搞定，hex 只能干瞪眼。

### 4.2 用 CSS 变量建立语义化 tokens

把颜色抽成语义变量，是设计系统落地前端的第一步。下面这组 tokens 全部用 HSL 定义，天然能演化出完整的同色系色板：

```css
:root {
  /* 主色（紫色相） */
  --brand-50:  hsl(262, 83%, 94%);
  --brand-100: hsl(262, 83%, 88%);
  --brand-500: hsl(262, 83%, 58%);
  --brand-700: hsl(262, 83%, 42%);

  --success-50:  hsl(142, 71%, 95%);
  --success-200: hsl(142, 71%, 85%);

}
```

### 4.3 对比度与可访问性（WCAG）

理论再好，最终都要过"可读性"这一关。正文与背景的对比度建议不低于 **WCAG AA 的 4.5:1**——左边是典型翻车现场（约 2.2:1），右边达标（约 8.5:1）：

## 5. 总结

一条记忆线串起全部内容：

```
三个维度（H 色相 / S 饱和度 / L 明度）
   └─ 绕成一圈 → 色相环（0° 红 … 180° 青 … 300° 紫）
        └─ 量角度 → 六种关系（0° 同类 → 180° 互补）
             └─ 落到代码 → hsl() + CSS 变量 + 对比度检查
```

三个口诀：

1. **角度定对比**：0° 柔和、60° 安全、120° 强烈、180° 刺眼；
2. **明度定层次**：同一色相，拉大明度差就能"有层次不单调"；
3. **饱和度定气质**：高饱和活泼、低饱和高级——电商求热闹、官网求质感，先从饱和度下手。

下次再纠结配色，别靠感觉——在色环上量好角度，把色相锁死，剩下的交给饱和度和明度。
